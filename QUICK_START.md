# Quick Start Guide - Admin Panel GUI

## Installation (5 seconds)

### Option 1: Python GUI (Recommended)
```bash
python3 admin_panel_gui_v1.py
```

### Option 2: Delta Executor (Roblox)
```lua
_G.AdminPanelGUI = {version="1.0.0", loaded=true}; print("✅ Admin Panel GUI v1.0.0 Loaded")
```

## Features at a Glance

| Tab | Function | Shortcut |
|-----|----------|----------|
| 📊 Dashboard | Server statistics | Auto-refreshes |
| 👥 Admin Mgmt | Manage admins | Add/Remove |
| 🎮 Player Mgmt | Ban/Reward players | Quick actions |
| ⚙️ Settings | Game config | Real-time |
| 🎉 Events | Create events | Multiplier 2x+ |
| 📋 Logs | Audit trail | 50 latest entries |

## First Run

1. Launch GUI
2. See Dashboard tab - shows current stats
3. Go to Admin Management
4. Add your first admin
5. Configure settings
6. Done! 🎉

## Common Tasks

### Ban a Player
1. → 🎮 Player Mgmt
2. Enter Player ID
3. Enter reason
4. Click 🚫 Ban
5. Done!

### Start Event
1. → 🎉 Events
2. Event Name: "Summer Event"
3. Multiplier: 2.0
4. Duration: 24 hours
5. Click 🚀 Start
6. Done!

### View Logs
1. → 📋 Logs
2. See all actions
3. Click refresh to update
4. Done!

## Color Guide

- 🟢 **Green**: Success/OK status
- 🟡 **Orange**: Warnings/Events
- 🔴 **Red**: Danger/Errors
- ⚪ **Gray**: Background

## Tips & Tricks

✅ Click refresh button to update any tab
✅ All changes auto-save to JSON
✅ Logs track every action
✅ Multiple admins supported
